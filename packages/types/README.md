# LINEJS Types

This package holds the various values and types of LINE.

Published on npm as `@evex-dev/linejs-types` and on JSR as
`@evex/linejs-types`.

```sh
npm install @evex-dev/linejs-types
```

## Examples

```ts
import type * as LINETypes from "@evex-dev/linejs-types";

type getContacts = () => Promise<LINETypes.Contact[]>;
```
